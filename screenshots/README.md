# Screenshots

Hướng dẫn chụp màn hình giao diện ứng dụng:
1. Chạy server theo README (`uvicorn app.main:app --port 8000`).
2. Mở http://localhost:8000 (trang chat) và http://localhost:8000/admin (quản trị) trên trình duyệt.
3. Chụp màn hình và lưu vào thư mục này (ví dụ `chat.png`, `admin-stats.png`).
